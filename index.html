About clustJs

clustJs is a lightweight JavaScript library for multivariate statistical visualization in the browser. It brings PCA, t-SNE, UMAP, hierarchical clustering, and heatmaps together behind a simple ES-module API — powered by D3.js. Its hierarchical clustering faithfully reproduces R's scale() → dist() → hclust() pipeline, including the way R handles missing values.

Load a CSV or a built-in dataset, pick a tool on the left, or call the SDK directly from the console. See the documentation for details.
